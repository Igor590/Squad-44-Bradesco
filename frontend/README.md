# Frontend integrado

Na raiz do pacote, leia LEIA_PRIMEIRO.md.

```sh
npm ci
npm run dev
```

Backend esperado: http://127.0.0.1:8080. Front: http://127.0.0.1:5173.
O proxy do Vite encaminha /api e mantém o cookie de sessão na mesma origem.

```sh
npm run build
npm run lint
```

A taxa da simulação é mensal. Nenhuma senha do PostgreSQL deve ser inserida neste projeto frontend.
